Here’s a React interview question you can use — phrased naturally like it would be asked in a real interview:


---

💬 React Interview Question: Currency Converter App

You need to build a Currency Converter component in React.

Requirements:

1. The component should fetch real-time currency conversion rates from a public API (like ExchangeRate API or any mock API).


2. There should be:

An input box where the user can enter an amount.

A dropdown to select the source currency (e.g., USD, EUR, INR, etc.).

Another dropdown to select the target currency.

A button to swap the source and target currencies.



3. When the user enters a value or changes a currency, it should automatically update the converted amount on the UI.


4. Handle loading and error states properly when fetching data.


5. Use React hooks (useState, useEffect) for managing state and side effects.



Bonus:

Debounce the API call so it doesn’t trigger for every keystroke.

Style it neatly with minimal CSS or Tailwind.



---

Example Prompt (for candidates):

> Implement a CurrencyConverter React component that fetches currency rates from an API and displays converted values. Include input for amount, two currency dropdowns, a swap button, and show the converted result dynamically.
